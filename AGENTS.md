# Reglas del proyecto

Este es un gestor de tareas por consola en Python (un solo archivo: `todo.py`).

## Git
- Una rama por funcionalidad: `feat/...`, `fix/...`, `docs/...`, `test/...`
- Commits pequeños y en formato Conventional Commits (`feat:`, `fix:`, `docs:`, `refactor:`, `test:`, `chore:`)
- Nunca hacer push directo a `main`
- Nunca ejecutar `git commit`, `git push` ni `git merge` sin que la persona lo pida

## Código
- Escribir en Python 3 estándar, sin librerías externas
- Comentarios y mensajes al usuario en español
- Antes de proponer un commit, ejecutar `python -m unittest`
