# Cambios

Todos los cambios importantes del proyecto se anotan aquí.
Formato basado en [Keep a Changelog](https://keepachangelog.com/es-ES/1.1.0/).

## [0.1.0] - 2026-10-14

### Agregado
- Comando `agregar` para crear tareas.
- Comando `listar` para ver las tareas.
- Comando `hecha` para marcar una tarea como completada.
- Comando `eliminar` para borrar una tarea.
- Pruebas automáticas con `unittest`.
