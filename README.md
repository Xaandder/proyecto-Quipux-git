# Gestor de tareas

Un gestor de tareas por consola hecho en Python.

Proyecto de práctica para aprender buenas prácticas de Git.

## Uso

```bash
python todo.py agregar "Aprender Git"
python todo.py listar
python todo.py hecha 1
python todo.py eliminar 1
```

## Pruebas

```bash
python -m unittest -v
```
